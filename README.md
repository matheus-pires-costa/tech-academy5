CN Estética e Bem-Estar
Projeto desenvolvido por Matheus Pires Costa como parte das atividades acadêmicas do curso superior (Tech Academy 5).

📋 Sobre o Projeto
O CN Estética e Bem-Estar é um sistema web Full-Stack desenvolvido para o gerenciamento completo de uma clínica estética. A aplicação automatiza o fluxo operacional diário, permitindo o controle rigoroso de clientes, o catálogo de procedimentos oferecidos e a agenda de marcações da clínica.
🚀 Tecnologias Utilizadas
Front-end: React, React Router DOM, Bootstrap e Vite.
Back-end: Node.js, Express, TypeScript e Prisma ORM.
Banco de Dados: PostgreSQL (hospedado na nuvem).
Testes: Jest para testes unitários.
Hospedagem & Deploy: Render (API Back-end e Banco de Dados) e InfinityFree (Front-end estático via FileZilla).
